# INSTALATION

instalation for demo is *simple*:

- Put model into the workspace
- ungroup and put folder in serverscriptservice
- configure the Config module and enjoy!

Instalation for Pro is more *advanced*:

- Install Plugin from this post and put it into plugins folder.
- open the Plugin and go on with the instalation.
- Configure permissions and adimin panel, and enjoy!
